# AI Usage Log

Per `CLAUDE.md` "Session Logging": one file per session, named `YYYY-MM-DD_<phase-description>.md`, containing every engineer prompt **verbatim, in order** — not summarized — plus which resulting code/docs were AI-generated vs. human-written, key decisions, experiments run, and issues encountered.

This is not a summary log (that's `logs/daily_standup.md`). This is the raw record, kept so the exact sequence of what was asked and decided can be reconstructed later — useful for the technical report's methodology section and for academic integrity documentation.
